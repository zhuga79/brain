# Skill Curator System

The Skill Curator manages the lifecycle, discovery, and routing of agent skills.

## Capabilities
- **Autonomous Skill Discovery**: Finds and evaluates new skills.
- **JIT Injection**: Just-In-Time injection of environments and dependencies (e.g., Opencode, Kilocode).
- **Benchmark Routing**: Routes tasks to skills based on observed benchmark reliability.
- **Fleet Monitoring**: Tracks usage and success rates across the agent fleet.
