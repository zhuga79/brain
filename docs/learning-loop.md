# Learning Loop

The Learning Loop captures operational knowledge and errors to improve future executions.

## Features
- **Auto-Defect Capture**: Automatically records pipeline failures as learning opportunities.
- **Human-Edit Capture**: Observes manual corrections and adapts templates.
- **Phase-Capture**: Summarizes learnings at the end of lifecycle phases.
- **Learning Dashboard**: Visualizes learning metrics and lesson applicability.
